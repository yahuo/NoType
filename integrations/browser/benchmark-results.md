# 2026-09-07 网页翻译测速与取舍

使用当前 NoType 的 Codex OAuth 请求通道，固定的合成样本包括：含数字与否定的短句、插件说明短段，以及包含金额、审批条件、百分比/百分点、URL、变量名的长段。未读取或发送实际网页及私人文档。认证未写入结果。

## 单段模式：每个模型 3 次真实请求

| 模型 / 推理强度 | 三个样本完整耗时（秒） | 三次合计（秒） |
|---|---|---|
| gpt-5.6-luna / none | 2.840 / 2.485 / 4.365 | 9.690 |
| gpt-5.4-mini / low | 2.076 / 2.134 / 5.794 | 10.004 |
| gpt-5.3-codex-spark / low | 3.779 / 2.482 / 2.070 | 8.331 |

人工检查这些译文，三者均保留了样本的主要含义、否定与审批条件，金额换算、百分比/百分点、URL、变量名均正确。Spark 在这个长段更快，短句并没有稳定优势。

## 批次模式：同样 3 段组成一次请求

| 模型 / 推理强度 | 首个输出片段（秒，可能仅为 JSON 前缀） | 完整耗时（秒） |
|---|---|---|
| gpt-5.6-luna / none | 2.067 | 5.424 |
| gpt-5.4-mini / low | 2.405 | 5.082 |
| gpt-5.3-codex-spark / low | 2.939 | 3.290 |

三者的输出均可解析为 3 个独立 JSON 行，ID 对应完整。Spark 总耗时更短，但首个输出更晚，且批量样本中把 `$2.5 billion` 保持为英文，中文表达也稍生硬。Luna 和 Mini 把金额译为 25 亿美元。

本轮默认保留 Luna / none：当前没有证明另一个模型在首字时间、整体速度与译文自然度上同时更优。未改动听写改写、英文翻译或选词翻译的模型，也未增加更高计费档位。

## 已安装本地通道：旧单段与新批次对照

从真实安装的 Native Messaging 连接程序，经 socket 调用运行中的 NoType，再请求真实模型。两次均为 Luna / none，使用上述相同 3 段；未经过 Chrome 的实际扩展 UI。

| 方式 | 请求次数 | 首个可显示中文（秒） | 全部完成（秒） | 返回帧数 |
|---|---:|---:|---:|---:|
| 逐段串行 | 3 | 3.092 | 9.087 | 3 |
| 小批次流式 | 1 | 3.718 | 6.862 | 178 |

本轮总等待减少约 24.5%，但首次中文出现晚了约 0.6 秒。新通道验证了多帧逐步返回，最终段落 ID、译文、数字、否定和 URL 均正确。真实页面还会受段落长短、视口位置与网络影响。

另用已安装连接程序验证取消与恢复：关闭浏览器侧输入管道后，连接程序在 0.009 秒内退出；随后新建连接的下一批翻译成功，返回 28 帧。此项同样未经过 Chrome 扩展 UI。

以上都是少量样本的单轮观察，调用顺序、服务排队、缓存和网络抖动没有被严格控制；不能作为稳定倍数或所有网页性能的保证。原始结果存放于仓库 `dist/model-benchmark/`；复测方式见同目录 README。
